# FamilyGram: Android design system

Статус: предлагаемый дизайн-контракт для новых семейных экранов. Не свидетельствует о готовности приложения. Визуальная опора из брифа — знакомый Telegram: плотный список, простой верхний бар, спокойный синий акцент, минимум декоративных поверхностей. Не переносить эту палитру на существующие чаты автоматически: сначала сопоставить с темой выбранной Android-базы.

## Color roles

| Android role / resource | Light | Dark | Назначение |
|---|---|---|---|
| primary / `fg_primary` | `#006397` | `#91CDFF` | Основное действие, активная ссылка |
| onPrimary / `fg_on_primary` | `#FFFFFF` | `#00334F` | Текст на primary |
| primaryContainer / `fg_primary_container` | `#D0E8FF` | `#004B73` | Выбранная строка, контекстное выделение |
| onPrimaryContainer / `fg_on_primary_container` | `#001D31` | `#D0E8FF` | Текст выбранной строки |
| surface / `fg_surface` | `#FAFCFF` | `#101418` | Основной фон |
| surfaceContainer / `fg_surface_container` | `#EDF1F5` | `#1C2024` | Группы настроек, нижний лист |
| surfaceContainerHigh / `fg_surface_container_high` | `#E7EBEF` | `#262B30` | Диалог, поднятая поверхность |
| onSurface / `fg_on_surface` | `#191C20` | `#E1E6EB` | Основной текст |
| onSurfaceVariant / `fg_on_surface_variant` | `#42474E` | `#C2C7CE` | Подписи, вторичная информация |
| outline / `fg_outline` | `#72777F` | `#8C9198` | Граница поля, значимый контур |
| outlineVariant / `fg_outline_variant` | `#C2C7CE` | `#42474E` | Нефункциональные разделители |
| error / `fg_error` | `#BA1A1A` | `#FFB4AB` | Ошибка, необратимое действие |
| onError / `fg_on_error` | `#FFFFFF` | `#690005` | Текст на error |
| success / `fg_success` | `#176B45` | `#8BD5AC` | Только подтверждённое состояние |
| warning / `fg_warning` | `#795900` | `#F1C65C` | Ограничение или требуемое действие |

Не кодировать состояние только цветом. У каждого статуса есть текст; значок помогает отличить его без чтения. Зелёный замок и подпись «Защищено» не применяются к одному лишь факту подключения. В XML предложены статические fallback-значения. Автоматический цвет по обоям — отдельная пользовательская опция после проверки обеих тем и контраста.

## Type

Системный Roboto / sans-serif. Размеры `sp`, отступы `dp`. Не отключать системное масштабирование и не ограничивать перенос ради высоты строки.

| Роль | Размер / line height | Вес | Применение |
|---|---|---|---|
| headlineSmall | 24 / 32 sp | 400 | Один заголовок onboarding |
| titleLarge | 22 / 28 sp | 400 | Заголовок верхнего бара |
| titleMedium | 16 / 24 sp | 500 | Название настройки, устройства, плагина |
| bodyLarge | 16 / 24 sp | 400 | Инструкции, ввод |
| bodyMedium | 14 / 20 sp | 400 | Описание настройки и статус |
| labelLarge | 14 / 20 sp | 500 | Кнопки |
| labelSmall | 12 / 16 sp | 500 | Метаданные, не основной текст |

Секреты не отображать в больших заголовках. Отпечатки ключей — системный monospace, только при наличии реального значения и функции сверки. Адрес хоста переносится; полное значение доступно в деталях. Не усекать действие или причину ошибки.

## Geometry

- Базовый шаг 4 dp. Рабочие интервалы: 4, 8, 12, 16, 24, 32.
- Боковые поля телефона 16 dp; у onboarding 24 dp при достаточной ширине, 16 dp на узком экране.
- Верхний бар: базово 64 dp плюс системный inset; контент ниже него.
- Строка настройки: min-height 64 dp, padding 16 dp по горизонтали и 12 dp по вертикали, гибкая высота. Подпись непосредственно под названием с интервалом 4 dp.
- Раздел группы: 24 dp сверху, 8 dp снизу. Списки на общей поверхности; карточки только для отдельного объекта/действия.
- Значки 24 dp; цель нажатия минимум 48×48 dp. Между независимыми целями минимум 8 dp. Вся строка переключателя — одна семантическая цель.
- Основная кнопка: min-height 48 dp, внутренние поля 24×12 dp, гибкая высота для увеличенного шрифта. Скругление 24 dp. На узком экране действия располагаются друг под другом.
- Поле ввода: min-height 56 dp, радиус 12 dp; label сохраняется после ввода. Ошибка идёт под полем, а не поверх него.
- Листы и диалоги используют стандартную геометрию Material; содержимое прокручивается при большом шрифте.
- Не добавлять карточку вокруг каждой настройки, градиенты, стекло, декоративные щиты, героя onboarding во весь экран.

## Components and states

| Компонент | Правило |
|---|---|
| Filled button | Одно главное действие на экран; loading сохраняет подпись и геометрию, исключает повторную отправку |
| Text button | Отмена, позже, повторная проверка; не слабее 48 dp по зоне касания |
| Switch row | Название + краткое последствие + switch; значение меняется после подтверждения операции или явного локального сохранения |
| Navigation row | Название + summary + chevron; не маскировать навигацию переключателем |
| Status row | Значок + статус + источник/время, когда важно; при потере актуальности писать «Нет свежих данных» |
| Inline error | Объяснение и конкретное действие; код диагностики в раскрываемых деталях |
| Snackbar | Короткое подтверждение обратимого действия; важная ошибка остаётся в контенте |
| Confirmation dialog | Только решение с последствиями; название действия, объект, эффект, конкретная кнопка |

Все интерактивные элементы: default, pressed/ripple, keyboard focus, disabled, loading, error. На указателе — штатный hover; не изобретать его для touch. Disabled должен иметь рядом причину, если она непонятна. Focus виден и не полагается на цвет текста. Скелетон только там, где известна структура; ожидание одобрения устройства — полноценное состояние, а не вечный spinner.

## Native behavior and accessibility

- Системный Back и predictive Back сохраняют ожидаемую навигацию. Отмена сетевой операции не должна автоматически означать отзыв заявки.
- Edge-to-edge учитывает status/navigation/IME/display-cutout insets. Клавиатура не перекрывает поле и основное действие.
- TalkBack: порядок чтения совпадает с визуальным. Строка switch сообщает label, роль, checked и доступность; декоративные значки исключены. Статус обновляется через polite live region без повторов при каждом poll.
- Цель контраста: обычный текст ≥4.5:1, крупный текст ≥3:1; значимые границы/контролы ≥3:1 относительно соседнего цвета. Отключённый вид не используется для критической инструкции.
- Проверить font scale 1.0, 1.3 и 2.0. Высоты контента не фиксировать; горизонтальный скролл текста запрещён. Длинные русские названия и ошибки переносятся.
- При Remove animations — мгновенное изменение или короткий fade. Обычные переходы 150–250 ms, без задержки доступа к данным.
- При ≥600 dp допускается master/detail; семейные настройки занимают колонку max-width 600 dp. В split-screen узкий режим возвращается к одному экрану. Порядок существующей Telegram-навигации сохраняется.
- Биометрия, разрешение камеры и разрешение VPN показываются системными диалогами после объяснения и действия пользователя; не рисовать их имитации.

## Implementation boundary

`design/android-res/` — XML-ready предложения для переноса в модуль приложения. Они не подключены к сборке и не заменяют существующую тему. Сначала связать semantic roles с темой выбранной базы; не встраивать hex в layouts. Строки с `%1$s` форматируются только реальными безопасными данными. HTML, секреты и URL из сервера не интерполируются как разметка.

Сценарии, состояния и критерии приёмки: [design/flows.md](design/flows.md). Проверка XML и контрастных пар: [design/validation.md](design/validation.md).
