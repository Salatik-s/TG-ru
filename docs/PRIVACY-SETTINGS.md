# Настройки призрака

Статус: проверенный итоговый Android preview12. Финальные снимки после исправления контраста и [отчёт](../qa/saved-media/PREVIEW12-RESULT.md) относятся к подписанному APK c16d5534…e72763c.

## Где открыть

На главном экране **S.A.A. → ⋮ → Настройки призрака**. Тот же экран доступен из обычных настроек. Технические системные настройки остаются внизу общего списка.

## Элементы управления

1. Общий режим призрака.
2. Скрывать статус «в сети».
3. Не отмечать сообщения прочитанными.
4. Скрывать набор текста.
5. Скрывать просмотр историй.
6. Возвращать статус «не в сети».
7. Сохранять удалённые сообщения.

Переключатели связаны с прежними действующими NekoConfig-фильтрами и настройкой локальной истории. Изменения сохраняются сразу. Обновление оформления не сбрасывает пользовательские значения.

## Оформление и доступность

Строки компактные, с названием и кратким пояснением. Цвета берутся из текущей темы Telegram; для недостаточно контрастного поясняющего текста и неактивного по значению переключателя предусмотрены читаемые fallback-цвета. Выключенный переключатель остаётся доступным для нажатия.

Нажимается вся строка и сам переключатель. Для screen reader строка представляется одним checkable Switch со своим текущим состоянием. Высота строки подстраивается под текст; списку оставлен scroll и системные отступы по краям экрана.

Итоговый подписанный APK проверен при масштабах шрифта **100%, 130% и 200%**, с реальными семью переключателями и восстановлением прежних настроек. Измеренный контраст поясняющего текста не ниже **4.5**, выключенного thumb/track не ниже **3**. Проверены реальный whole-row click, checkable/accessibility состояние и восстановление реальных read/typing-фильтров. Все шесть top/bottom screenshots выполнены после финального исправления контраста. Системный масштаб шрифта телефона не менялся: тест применял activity-only override.

## Границы функций

Ghost управляет событиями именно этого клиента и учитывает существующие исключения чатов. Другие Telegram-сеансы и поведение сервера независимы. Локальная история хранит только сообщения, которые клиент успел получить до удаления; ранее не полученную историю она не восстанавливает.
