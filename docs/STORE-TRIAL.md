# Пробный доступ TG-ru Store

Войдите в кабинет и нажмите «Попробовать 5 часов бесплатно». Отсчёт начинается сразу. Кабинет показывает срок окончания по Москве. Для активации Android введите логин и пароль кабинета. После подключения откроется обычный вход в Telegram.

## Срок и выдача

- Проба выдаётся один раз на аккаунт и длится ровно 18 000 секунд по часам кабинета. Повторные и параллельные запросы возвращают исходный срок. Смена телефона его не продлевает.
- Оператор может отдельно выдать доступ из консоли. Активный срок определяется по самому позднему окончанию пробы, ручной выдачи или подписки. Онлайн-оплата временно недоступна. Страница оплаты ведёт в поддержку.
- Активация и продление требуют подписи установки. Кабинет передаёт шлюзу подписанный допуск максимум на 75 секунд в пределах действующего срока. У каждого аккаунта может быть до трёх активных устройств.
- Шлюз закрывает доступ по истечении допуска. При отвязке устройства следующий запрос на продление отклоняется. Существующий допуск истекает не позднее чем через 75 секунд. [Протокол и запуск](STORE-GATEWAY.md)

## Проверки

Тесты покрывают вход и CSRF, одновременные попытки запуска пробы, отказ без подписки, предел устройств, подмену подписи, повтор запроса, истечение на 18 000-й секунде и остановку выдачи при отказе шлюза. Совместимость прежних клиентов проверяется отдельно.

```powershell
node --test local-store/store.test.mjs server/test/store-gateway.test.mjs tests/compat/preview.test.mjs
```
