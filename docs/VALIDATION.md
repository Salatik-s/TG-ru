# Проверки и ограничения

Дата сессии: 8 ноября 2026 года. Финальный подписанный артефакт — `0.1.0-preview9`, versionCode `10009`, SHA-256 `f3ccad9e4ee3ee1554c5d1c276fbf8e0308e88920947a064e4797ec23aa08ea1`.

Основной актуальный отчёт: [qa/saved-media/RESULT.md](../qa/saved-media/RESULT.md). Финальные прогоны: Python/документы 18 секунд, медиа 18 секунд, история/призрак 2 секунды, цикл владельца 1 секунда, финальная навигация 5 секунд. Этот документ описывает зафиксированные проверки текущей Android-ветки. Итоговый артефакт должен иметь собственный отчёт с версией и SHA-256; результаты предыдущего preview нельзя выдавать за проверку произвольной будущей сборки.

## Реальный телефон

Android 15, arm64. Установка обновлялась с тем же package ID и сертификатом; пользовательский аккаунт и ключ допуска сохранялись. Автоматические отправки разрешены только в собственное «Избранное». Тесты генерируют свои файлы и не отправляют личные документы, фото, аудио или историю.

| Проверка | Наблюдаемый результат |
|---|---|
| Документ 128 КиБ | Обычная загрузка, серверный ACK, новое сетевое скачивание, совпадающий SHA-256 |
| Документ 12 МиБ + 197 байт | ACK, новое скачивание по полученному location, совпадающий SHA-256 |
| Синтетическое фото 512×512 | ACK, валидный file_reference, новое скачивание JPEG и декодирование 512×512 |
| Владелец | Сервер подтвердил привязку установки и доступ к списку устройств |
| Временное устройство | Приглашение → ожидание → запрет администрирования → одобрение → доступ к конфигурации → повторный запрет администрирования → отзыв → отказ в конфигурации |
| Призрак | На входе штатных interceptors проверены блокировка read/typing, принудительный offline и возврат обычного поведения после отключения |
| История удаления | Реальное удаление собственного нового сообщения; локальная история сохранила текст, реальный экран истории нашёл именно тестовое сообщение |
| Python из чата | Реальный Python-блок в новом self-сообщении → пункт контекстного меню → явный запуск → результат 45/AAS |
| Ограничения Python | Ошибка синтаксиса показана; бесконечный цикл остановлен по лимиту; сеть и приватная файловая область приложения недоступны |
| Документы | PDF с двумя страницами и переключением; DOCX с символами `& < >`; бинарный DOC, ODT, RTF и TXT прочитаны локальным просмотрщиком |
| Начальное состояние дополнений | Python и документы отключены по умолчанию; пользователь включает их в настройках |

Проверка ghost interceptors — контролируемая проверка клиентского поведения. Она не доказывает, что другой пользователь никогда не увидит ни одного следа активности во всех экранах Telegram.

## Навигация финального preview9

На установленном финальном preview9 проверены label `TG-ru`, настоящий видимый заголовок `S.A.A.`, нажатие пункта главного меню **⋮ → Настройки призрака** и семь элементов управления этого экрана. Два отдельных переключателя сопоставлены с действующими фильтрами отправки. Основные настройки содержат отдельные пункты призрака, плагинов и устройств владельца. Пункт системных настроек расположен после всех стандартных интерактивных строк. Python и шесть форматов документов повторно прошли проверку на preview9.

Непроверенное дополнительное изменение TCP drain адаптера звонков не включено в APK. Исходники выпущенного адаптера возвращены к baseline; возможная экспериментальная копия в `qa/unreleased` не обозначает выпущенную функцию.

## Публичный серверный путь

Проверка WSS → собственный хост → выбранный VPN → Telegram выполнена до всех пяти закреплённых production DC. Успех определялся корректным MTProto `resPQ` с совпадающим nonce. Это сильнее простого TCP connect и не требует чтения переписки.

Серверные проверки отдельно покрывают одноразовость приглашения, подпись P-256 и привязку точного payload, срок/повтор proofs, задержку 300 секунд, блокировку десятой ошибки, права владельца, отзыв и ограниченные SSE-сигналы. Опциональные real-Xray тесты требуют конкретного окружения; смотри вывод запуска, а не только общее число тестов.

## Что не подтверждено

- Реальный голосовой/видеозвонок с собеседником и групповые звонки.
- Камера, микрофон и полный обычный UI-путь голосового сообщения/видео. Отправка файла не равнозначна этим проверкам.
- Длительная доставка уведомлений в Doze, после принудительной остановки и при разных OEM-ограничениях.
- Все комбинации стороннего VPN, split tunneling, captive portal и мобильных операторов.
- Полная upstream Gradle-сборка, все старые Android/WebView и iOS/IPA.
- Неограниченная нагрузка сервера и круглосуточная доступность.

## Безопасные скриншоты

`docs/screenshots/` содержит только реальные экраны с собственными synthetic fixtures. Перед добавлением нового скриншота проверяются отсутствие личных чатов, телефонов, ключей, токенов, кодов приглашения и идентификаторов допуска. Экран списка чатов пользователя целиком сюда не добавляется.
