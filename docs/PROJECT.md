# TG-ru · S.A.A.

Приложение и файл — **TG-ru**, `TG-ru.apk`; заголовок списка чатов — **S.A.A.** Основа: exteraless `v13.1.1-beta15`, Telegram 13.1.1, закреплённый commit `c83765c4151d50ba514325ddf0a3262769729dc6`. Внутренний пакет `com.salatik.familygram` и ключ подписи сохранены для обновления установленного приложения без потери аккаунта и ключа Android Keystore.

## Устройство проекта

- `overlay/` — семейный допуск, Android Keystore P-256, экран приглашения, настройки и клиент уведомлений.
- `server/` — API допуска, SQLite, одноразовые приглашения, владелец через локальный socket, relay сигналов Telegram SimplePush.
- `deploy/` — изолированное обновление `/opt/familygram` и PowerShell-команды владельца.
- `tunnel/` — встроенное Xray-ядро, VLESS/REALITY, TCP и UDP, две Android ABI.
- `native/` — точная копия MTProto networking с проверкой ABI оригинального клиента; прямое соединение с Telegram заменено приватным дескриптором транспорта.
- `calls/` — адаптер сокетов оригинального VoIP-модуля, проверка исходного ELF и вызовов через GOT, отзыв соединений.
- `build-support/` — воспроизводимая подготовка закреплённого APK, семейные настройки, сборка, проверки DEX/ресурсов/ELF и подпись.
- `qa/` — локальные стенды и отдельный instrumentation APK. Материалы QA не включаются в приложение.

## Сеть и доступ

Первый запуск проверяет ключ установки через `https://24projects.ru:8443`. Одноразовое приглашение переводит установку в ожидание. Владелец сравнивает отпечаток и одобряет устройство. Основной транспорт — VLESS поверх TLS/WebSocket `/v1/transport` на TCP 8443 с проверкой сертификата домена. REALITY на TCP 18443 сохранён для совместимости. После допуска открывается обычный вход в Telegram.

Трафик MTProto и сокеты нативного модуля звонков передаются встроенным ядром через собственный шлюз. Отдельный системный `VpnService` приложение не запускает. Профиль, ключ устройства и счётчик допуска не являются общим секретом, зашитым в APK. На сервере нет Telegram-сессий пользователей.

Серверный выход использует сохранённые VPN-профили владельца: native VLESS/Trojan/Shadowsocks, без внутренней SOCKS-цепочки и без прямого fallback. Профили импортируются из кэша существующего VPN и локального экспорта в приватный `/opt/familygram/data/egress.json`; подписка не запрашивается, новая клиентская идентичность не создаётся. Обычные узлы перебираются перед БС-резервом. Каждый выбранный маршрут проверяется ответом MTProto `resPQ` через Obfuscated2 с совпадающим nonce; активный узел повторно проверяется раз в 30 секунд. При отказе маршрут снимается, затем выбирается следующий; работающий БС-узел периодически проверяет восстановление обычных узлов. Проверки не входят в Telegram-аккаунт.

Каждая неверная попытка вызывает серверную задержку 300 секунд. Десять последовательных ошибок блокируют установку. Временные IP-лимиты дополняют защиту; постоянной аппаратной привязки по MAC нет. Переустановка создаёт новую идентичность, но не выдаёт доступ без нового приглашения и одобрения.

Допуск обновляется раз в минуту. Нативная аренда ограничена 75 секундами и учитывает сон устройства. При отзыве или потере допуска соединения закрываются. Сбой единственного хоста останавливает работу клиента.

## Уведомления

Telegram SimplePush отправляет на хост только версию события. Хост передаёт сигнал через авторизованный SSE-канал, приложение возобновляет MTProto и получает сообщения. Relay не хранит текст переписки. Android foreground service показывает системное уведомление о фоновом соединении. Доставка в фоне зависит от системных разрешений, энергосбережения и сети; она требует испытания на физических телефонах.

## Функции и приватность

Сохранены клиентские экраны Telegram. Первый запуск применяет точечный набор стандартных настроек оформления; индивидуальные темы и обои не затираются. Семейные настройки ведут в существующие экраны режима призрака, локальной истории и плагинов. История сохраняет полученные клиентом сообщения. Код установленных плагинов остаётся доверенной частью приложения.

Облачные чаты остаются облачными чатами Telegram. Собственный шлюз не превращает их в секретные чаты и не исключает риски на телефоне, у собеседника или в коде плагина. На период проверки звонков отключён прямой P2P: используется маршрут через серверы-ретрансляторы.

## Обновление сервера

Для текущего набора клиентских функций preview11 обновление хоста не требуется. Команды ниже предназначены для отдельной установки или обслуживания сервера.

Сначала `powershell.exe -NoProfile -ExecutionPolicy Bypass -File deploy/Deploy.ps1 -PlanOnly`, затем та же команда без `-PlanOnly`. Реальный запуск требует SSH-доступа владельца. Пароль не хранится в пакете. Инсталлятор проверяет сертификат, порты, Docker, свободные память и диск, сохраняет другие проекты и выполняет откат только служб FamilyGram при ошибке.

Владелец управляет приглашениями и устройствами через `deploy/Manage.ps1 invite|list|approve|revoke`; для одобрения и отзыва требуется полный ID из списка.

Если для FamilyGram нужно освободить оперативную память, `Deploy.ps1 -PauseVoiceRooms` сначала проверит и остановит только контейнеры Compose-проекта `voicerooms` из `/opt/voicerooms`. Остановка сохраняет контейнеры, тома и конфигурацию; скрипт печатает память до/после и команду возврата. VoiceRooms будет недоступен, пока его не запустят обратно.

Сервер использует готовые Node/nginx-образы с закреплёнными digest и заранее проверенный Xray; сборка на VPS исключена. По явному решению владельца проверка RAM стала только диагностической: порог допуска, собственные лимиты памяти контейнеров и настройки heap убраны. После запуска проверяются TLS-health, остановки/перезапуски и реальные OOM-события в течение начального окна наблюдения. При сбое выводятся журналы FamilyGram и откатываются только его службы. Это проверка запуска, а не нагрузочное испытание.

TLS использует существующий сертификат для `24projects.ru`, без нового домена. Инсталлятор проверяет Certbot lineages (сначала имя `24projects-24projects.ru` из установщика сайта), доверенную цепочку/имя, срок и соответствие ключа. Контейнер получает только выбранные live/archive каталоги read-only; сохранены исходные относительные ссылки Certbot и подключён собственный reload-hook для фактического lineage. Сертификаты сайта не перевыпускаются и не заменяются.

`Retry.ps1` повторно использует конкретный загруженный каталог из последнего лога владельца. Маленький updater проверяет исходные/новые SHA-256 трёх публичных файлов и неизменность серверного кода/Xray до записи, затем запускает тот же инсталлятор. Повторная передача Xray не требуется. Для другой загрузки нужно подготовить новый `deploy/retry-staged.json` через `build-support/prepare-retry.py` с её точными исходными hash и путём.

`Fix-Egress.ps1` — подготовленное исправление прямого выхода в уже загруженной версии. Оно проверяет и обновляет только разрешённые публичные файлы, импортирует сохранённые профили на самом хосте и устанавливает новый релиз FamilyGram. Существующий VPN не меняется. После активации проверяется вся серверная цепочка REALITY → выбранный VPN → MTProto Telegram с UUID уже одобренного устройства только в памяти хоста. Проверка телефона остаётся отдельной. APK и допуск установки сохраняются. Изменившиеся профили можно повторно импортировать тем же инсталлятором; snapshot не является живой подпиской.

## Управление с телефона

Настройки → Устройства семьи. Строка видна привязанной установке владельца. Можно создать одноразовое приглашение на 24 часа, одобрить устройство по отпечатку и отозвать доступ. Привязка задаётся только через локальный административный socket на хосте (`node owner.mjs set-owner APPROVED_DEVICE_ID`). Публичного самоназначения нет; сервер проверяет право владельца и подписанное действие при каждом запросе. Одобренные семейные устройства не получают права владельца.

## Встроенные дополнения

Настройки → Плагины. Python и просмотр документов предустановлены. На новой установке они выключены; обновление сохраняет ранее выбранное пользователем состояние. Обычный менеджер сторонних плагинов открывается отдельной кнопкой.

- **Python в чате:** после включения дополнения под блоком Python появляется кнопка «Запустить». Вывод показывается прямо под блоком; длинный вывод можно развернуть и скопировать. Остановить можно и загрузку среды, и выполнение. Расширенный редактор остаётся доступен из меню сообщения. CPython/Pyodide 314.0.7 включён в APK, CDN не используется. Каждый запуск получает новый Web Worker и виртуальную файловую систему, сеть закрыта, JavaScript-моста к Android/Telegram нет. На запуск среды отводится 30 секунд, на исполнение кода после готовности среды — отдельно 10 секунд. Ошибка загрузки не выдаётся за превышение времени исполнения. Исключения Python показывают тип, traceback и строку кода; вывод ограничен 64 КБ. Результат остаётся на телефоне и не отправляется в чат. Пакеты автоматически не скачиваются.
- **Документы:** PDF открывается постранично, с переходами между страницами, увеличением двумя пальцами и двойным касанием. При увеличении страница повторно отрисовывается с повышенной детализацией. DOCX и ODT поддерживают базовое форматирование; сложная вёрстка может отличаться от исходной. Для старых DOC и RTF используется текстовый просмотр, как и для обычных текстовых файлов. Файл до 32 МиБ, текст до 200 000 символов. Парсеры и PdfRenderer работают в отдельном `isolatedProcess`, получают только дескриптор для чтения и не используют онлайн-просмотрщик. Для DOC включён Apache POI. Макросы не исполняются.
- **Локальная расшифровка:** кнопка у голосового сообщения или видеокружка запускает распознавание загруженного файла на телефоне и показывает текст в сообщении. Используется системная on-device модель, без семейного хоста, Whisper или Telegram Premium. Облачного fallback и перехода на запись микрофона нет. Нужен Android API 33+ и провайдер, отдельно проверенный на чтении файла. Встроенная проверка допускает конкретный протестированный Google AiAi на Android 15: версия `12872254`. Другие версии и устройства не считаются совместимыми автоматически. Для выбранного языка требуется установленная системная модель; её загрузка требует сети, последующее распознавание выполняется локально. Поддержка загрузки модели через приложение требует API 34+. Аудио подаётся в реальном времени; файл ограничен 16 МиБ и 5 минутами. Проверка синтетической русской речи на этом телефоне прошла без разрешения микрофона у отдельного тестового приложения. Это не обещание совместимости со всеми Android-телефонами.
- **Удалённые сообщения:** сохранение включено на этом телефоне; есть явный переключатель в настройках призрака. В конкретном чате → меню → «Просмотреть удалённые». Сохраняются сообщения, полученные приложением до удаления. Предыдущие удаления до включения не восстанавливаются. Ghost-переключатели сохраняют пользовательский выбор.

Лицензии зависимостей включены в assets `familygram/runner/runtime` и `familygram/document-licenses`. Telegram остаётся облачным сервисом; собственный транспорт не переносит его серверную историю на семейный VPS.

## Проверки и ограничения

Актуальные физические проверки: `qa/saved-media/RESULT.md`. На Android 15 проверены владелец, приглашение/одобрение/отзыв временного устройства и отказ ему в правах владельца, отправка и свежая загрузка синтетических файлов, Python из меню сообщения, ограничения интерпретатора, просмотр документов и локальная история реального удаления в «Избранном». Пять производственных DC ответили MTProto через публичный WSS → VPN. Старые отчёты относятся к своим версиям. Звонки с собеседником, камера/микрофон и длительная фоновая доставка этими проверками не подтверждены. Все отправки выполнялись только себе. Работа над iOS/IPA отложена; в этот Android-этап она не входит. Новые функции preview11 описаны выше; это описание поведения, а не утверждение о завершённой проверке финального APK. Результаты конкретных сборок фиксируются в их QA-отчётах.

Ключ подписи хранится отдельно от репозитория и APK в приватном каталоге владельца. Для последующих обновлений нужен тот же ключ.

## Навигация

Название приложения и APK — **TG-ru** / **TG-ru.apk**; заголовок списка чатов — **S.A.A.**

- Главная → ⋮ → **Настройки призрака**. Тот же раздел доступен в обычных настройках. Единый экран содержит общий переключатель, отдельные настройки статуса в сети, прочтения, набора текста, историй, возврата offline и хранения удалённых сообщений. Изменения применяются к реальным настройкам фильтров форка.
- Настройки → **Плагины**: Python и просмотр документов: предустановлены, выключены только на новой установке; существующий выбор сохраняется.
- Настройки → **Устройства семьи**: только на привязанной установке владельца.
- **Системные настройки** находятся в самом низу обычных настроек, перед строкой версии: подключение, отпечаток устройства и прежние расширенные экраны клиента. Штатные разделы Telegram сохранены; при поиске дополнительные строки не примешиваются к результатам.

Ghost действует на этом клиенте: другие сеансы и исключения отдельных чатов могут отправлять сведения об активности. Уже отправленные отметки нельзя отменить. Локальная история не восстанавливает сообщения, которые клиент не получил до удаления.
