# PR-03: совместимость preview9–17

Серверные маршруты, таблицы и ключи не меняются. Имитатор подписывает запросы новым P-256 ключом на каждом прогоне и использует только локальный HTTP, SQLite в памяти и адреса `.invalid` в ответах.

```powershell
node --test tests/compat/preview.test.mjs
```

Можно указать локальный каталог исходников другого шлюза переменной `COMPAT_GATEWAY_DIR`. Обе проверенные ревизии: исходники preview12 на `6d578d2` и исходники preview17 на `0ed7e51`. На каждой прошли все девять сценариев.

- C1: подписанный запрос статуса, приглашение, отказ в маршруте до одобрения, одобрение, получение параметров и отказ при повторе доказательства.
- C2: 15 продлений через 60 секунд по управляемым часам. Перед каждым продлением прежний SSE-токен ещё действует, идентификатор маршрута стабилен. Непродлённый токен отклоняется после истечения.

Имитатор воспроизводит общий контракт /v1 для девяти preview. Эталонные ответы фиксируют поля, типы и порядок этапов; временные значения нормализуются после проверки формата и связей. Дополнительное поле `developer_username` проверяется отдельно, если шлюз его возвращает.

Это проверка HTTP-контракта в локальном процессе. Она не запускает девять исторических APK, реальный Xray или Telegram и не проверяет длительный звонок. Для проверки на телефонах подготовить установочные артефакты соответствующих версий и отдельные устройства, без переустановки рабочих клиентов.
