# Проверка TG-ru Store preview25

Версия Android `0.1.0-preview25-store`, код `10026`.
SHA-256: `2d8b023f17602f22aa10bba633180153d3d5b1249c2806898d22338b6eddee48`.
APK подписан тем же сертификатом, что preview24. Проверены подписи v2/v3, выравнивание 16 КиБ, уникальность 64 310 классов в 10 DEX и сохранение публичных идентификаторов ресурсов.

| Сценарий | Результат |
| --- | --- |
| Ручная проверка версии | В Store обработчик больше не выходит без ответа. Android-инструментация подтвердила диалог со ссылкой на загрузки при ответе 404 от рабочего хоста. Новый API локально вернул точные метаданные APK. Сквозной ответ «доступна новая версия» на рабочем хосте требует публикации API. |
| Вход | На тестовом Android пройдены активация Store, приветствие Telegram, запрос системного разрешения и переход к полю номера после отказа в разрешении. Номер не вводили. Тестовое устройство отвязано после проверки. |
| Тексты | Проверены разметка и текст приветствия TG-ru. Упакованные ресурсы Telegram содержат обновлённые русские и английские строки. На уже использованном эмуляторе унаследованный экран продолжил показывать прежний английский текст. Возможный источник — сохранённый языковой пакет. |
| Поле ввода | Сверены штатные жесты записи в исходниках Telegram и коде форка. Отключены унаследованные настройки раскладки. Запись голосового и кружочка с действующим аккаунтом на физическом устройстве не проверена. |
| Обрыв сети | На связанной установке финальный APK оставался в Telegram после 82 секунд без сети и после её возврата. На промежуточной сборке с открытым экраном восстановления Telegram вернулся автоматически за первые 4 секунды после включения сети. Доставка сообщений после восстановления с действующим аккаунтом не проверена. |
| Сервер | 79 тестов Node.js, включая реальный Xray, и 5 тестов маршрутов Nginx прошли. |

Физический телефон и рабочий хост при проверке не обновлялись. Сборка не проходила полную проверку звонков, фоновых уведомлений и записи медиа с авторизованным Telegram.
