# Фоновое служебное уведомление TG-ru

Статус: проверенный итоговый Android preview12. Собственная instrumentation подтвердила foreground-service уведомление, реальный `telegram_connected=true`, тихий прежний канал и завершилась `OWN_NOTIFICATION_PASS`. [Отчёт](../qa/saved-media/PREVIEW12-RESULT.md).

## Что отображается

Название — **TG-ru**. Текст — **«Соединено с Telegram»**, когда выбранный аккаунт имеет штатный `ConnectionStateConnected`; иначе **«Подключение к Telegram…»**. Проверяется состояние Telegram-клиента и действующий семейный допуск. Наличие SSE-канала или доступность шлюза сами по себе не объявляются успешным соединением Telegram.

Состояние перепроверяется каждые две секунды, а уведомление обновляется только при смене текста. Нажатие открывает обычное приложение. Служебное уведомление не содержит содержимого чатов и не пересылается на сопряжённые устройства.

## Поведение канала

Сохранён прежний ID канала `familygram_push_connection`, поэтому существующие настройки Android для него не сбрасываются. Для нового канала задаётся низкая важность. Обновления используют `onlyAlertOnce`, минимальный приоритет и не показывают время каждого обновления. Это спокойное постоянное уведомление foreground service, а не новые всплывающие сообщения при каждом обновлении состояния.

Выбор пользователя в уже созданном системном канале сохраняет силу. Приложение не отключает системную защиту, не меняет глобальные разрешения и не удаляет обязательное foreground-service уведомление в обход Android.

## Проверки и границы

Тестовая instrumentation проверяет только уведомления собственного пакета TG-ru, его канал, признаки ongoing и фактический Telegram-connected state. Чужие уведомления и тексты переписки не извлекаются. Значения пользовательских настроек сохраняются.

Эта проверка не заменяет длительное испытание доставки сообщений в Doze, после остановки процесса, при ограничениях производителя телефона и при потере сети. Эти границы предыдущей версии остаются в силе. Серверный SSE, VPN и допуски этим изменением не развёртываются заново.
