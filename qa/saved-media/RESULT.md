## Изменения

- Служебное уведомление: заголовок TG-ru, при подтверждённом соединении выбранного Telegram-аккаунта — «Соединено с Telegram», в других состояниях — «Подключение к Telegram…». Доступность SSE/хоста не выдаётся за соединение с Telegram. Прежний ID канала сохранён, имя канала обновлено. Уведомление тихое, без времени, с LOW/PRIORITY_MIN/onlyAlertOnce/localOnly; фактическое сворачивание определяется Android и существующими настройками пользователя. Каналы обычных сообщений, их имя/текст/ответ не изменялись.
- Настройки призрака: фиксированная верхняя панель, компактные строки с подписью рядом с переключателем, группы и разделители, цвета текущей темы Telegram. Выключенные переключатели видимы в тёмной теме. Вторичный текст приведён к контрасту не ниже 4.5 на обеих поверхностях; выключенный thumb/track — не ниже 3. Семь прежних переключателей используют прежние настройки Neko/FamilyFeatures, без второй базы предпочтений.
