# Публикация TG-ru Store

Сборка для сайта должна быть подписана ключом TG-ru, содержать маркер Store и обращаться к рабочему HTTPS. Скрипт отклоняет сборку для USB-тестов. Проверить APK и состав пакета можно локально с параметром `-PlanOnly`.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\deploy\store\Publish-Store.ps1
```

OpenSSH запрашивает пароль при загрузке и при запуске установки, если для сервера не настроен ключ. Скрипт проверяет хост через OpenSSH и не сохраняет пароль.

Установка использует работающие Docker, Nginx и TLS. Store запускает два контейнера из закреплённого образа Node, который уже установлен для FamilyGram. База кабинета и данные шлюза хранятся в `/opt/tg-ru-store/data`. Контейнеры запускаются с отдельными непривилегированными UID, без доступа к Docker socket. Снимок зашифрованных исходящих маршрутов и проверенный Xray подключаются только для чтения.

Контейнеры используют сетевое пространство хоста для связи через loopback. Служебные порты 48185 и 48186 слушают только `127.0.0.1`. Снаружи доступны HTTPS сайта и REALITY на TCP 28443. При активном UFW скрипт добавляет правило только для этого порта, если существующие правила его не затрагивают. Фильтры хостинг-провайдера проверяются отдельно.

Старые `/index.html`, `/download/TG-ru.apk`, API 8443 и REALITY 18443 продолжают работать. Новая загрузка использует одноразовый билет кабинета и отдельный внутренний маршрут Nginx. При сбое проверок на сервере установка восстанавливает прежнюю конфигурацию Nginx и контейнеры Store. База кабинета сохраняется для повторной попытки.

После первой установки сайт и кабинет можно обновлять отдельно. Скрипт отправляет страницы, стили, тексты и код кабинета, перезапускает только веб-контейнер и при сбое проверок возвращает прежние файлы.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\deploy\store\Update-Home.ps1
```

Доступ зарегистрированному пользователю выдаётся из консоли хоста. Для START на 30 дней:

```sh
docker exec tg-ru-store-web-1 node local-store/owner.mjs grant user_login 30 --reason gift
```

Для PRO на 90 дней:

```sh
docker exec tg-ru-store-web-1 node local-store/owner.mjs grant user_login 90 --reason gift --plan pro
```
